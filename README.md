# MDFRNet

Resources for **MDFRNet: Modality-differentiated fusion and prediction-guided hierarchical refinement for RGB-D salient object detection**.

The source code and trained model will be released after the paper is accepted for publication.

## Datasets

The benchmark dataset package is available from [Baidu Netdisk](https://pan.baidu.com/s/1O2IGA3riO-poDBOwTu7Yug?pwd=sq75) (extraction code: `sq75`, file: `datasets.zip`).

Each dataset contains `RGB`, `GT`, and `Depth` folders. Please cite the original dataset papers and follow their usage terms.

## Saliency maps

The saliency maps of MDFRNet are available from [Baidu Netdisk](https://pan.baidu.com/s/1YNrZ9FTdCIG1EzX5LHF70w?pwd=hx55) (extraction code: `hx55`, file: `best.zip`).

The package contains predictions for DUT-D, LFSD, NJU2K, NLPR, SIP, and STERE, organized as `best/<dataset>/`.

## Code Availability

The source code and trained model will be made publicly available after the associated paper is accepted for publication.
